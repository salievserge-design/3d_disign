# Шрифты и эталон пропорций

| Файл | Что это | Источник |
|---|---|---|
| `RoadNumbers2.0.ttf` | шрифт российских регистрационных знаков (v2.003, 2009), свободно распространяемый | [ulex/generate_license_plates](https://github.com/ulex/generate_license_plates) |
| `ru.svg` | шаблон номерного знака по ГОСТ Р 50577 — из него взяты пропорции окантовки, разделителя и высоты знаков | там же |

В шрифте есть только цифры и латинские двойники «номерных» кириллических букв
(А В Е К М Н О Р С Т У Х → A B E K M H O P C T Y X) — генератор делает эту подмену сам.
Латиницы R/U/S в шрифте нет, поэтому надпись «RUS» набирается DejaVu Sans Bold
(поставляется вместе с matplotlib, лицензия Bitstream Vera).
